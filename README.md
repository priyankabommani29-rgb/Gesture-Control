# 🖐️ Gesture Control

A real-time computer vision application that enables touchless system control using hand gestures. The project uses a webcam to detect hand landmarks and translates specific gestures into system actions such as cursor movement and volume control.

## ✨ Features

* Real-time hand tracking using a webcam
* Gesture-based cursor movement
* System volume control using finger distance
* Smooth and responsive interaction
* Contactless human-computer interaction

## 🛠️ Tech Stack

* Python
* OpenCV
* MediaPipe
* PyAutoGUI
* Pycaw
* NumPy

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/priyankabommani29-rgb/Gesture-Control.git
cd Gesture-Control
```

### 2. Create a virtual environment

```bash
python -m venv venv
```

Activate it:

**Windows**

```bash
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python main.py
```

## 🎮 Supported Gestures

* 👆 Index Finger → Move Mouse Cursor
* ✌️ Index + Middle Finger → Left Click
* 🤏 Thumb + Index Finger Distance → Volume Control
